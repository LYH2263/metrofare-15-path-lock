# 13-metrofare（地铁票价）

Metrofare — 站间最短站数 + 分段票价表

## 启动

```bash
docker compose up --build
```

| 入口 | 地址 |
| --- | --- |
| 前端 | http://localhost:4200 |
| API | http://localhost:9200 |

## 主链

选起终点站 → 按站数/里程规则算票价 → 出示票价卡

## 途经锁定

- 试算分两种：**只读试算**按当前图实时重算，不落库；**试算并锁定**把途经站序列、站数、票价快照进记录。
- 记录按编号打开时展示锁定当时的途经/站数/票价，之后增边、删边、改票价表都不影响。
- 记录详情可"按当前图只读再试算"，结果只作对比展示，不写回记录；删除记录只删本行，不影响其他记录。

## 技术栈

Python 3.12 + FastAPI + SQLite；Vue 3 + Vite + Nginx。
